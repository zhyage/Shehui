## 一、地球仪与经纬网

### 1. 经线与纬线 ■背

| 对比 | 纬线 | 经线（子午线） |
|------|------|-------------|
| **形状** | 圆形（除极点） | 半圆形 |
| **长度** | 从赤道向两极递减 | 等长 |
| **指示方向** | **东西**方向 | **南北**方向 |
| **度数范围** | 0°—90° | 0°—180° |
| **0°线** | **赤道**（最长的纬线） | **本初子午线**（英国格林尼治） |

### 2. 重要的纬线和经线 ■背

| 名称 | 度数 | 意义 |
|------|------|------|
| **赤道** | 0°纬线 | 南北半球分界线 |
| **南北回归线** | 23.5°N / 23.5°S | 热带与温带分界 |
| **南北极圈** | 66.5°N / 66.5°S | 温带与寒带分界 |
| **本初子午线** | 0°经线 | 东经西经分界 |
| **20°W和160°E** | — | **东西半球分界线** |

> **东西半球划分口诀**："**小小为东，大大为西**"（东半球范围：20°W→0°→160°E）

### 3. 高中低纬度划分 ◆理解

| 纬度范围 | 名称 |
|---------|------|
| 0°—30° | 低纬度 |
| 30°—60° | 中纬度 |
| 60°—90° | 高纬度 |

### 4. 五带的划分 ◆理解

- **热带**：南回归线—北回归线（有太阳直射）
- **温带**（北温带/南温带）：回归线—极圈
- **寒带**（北寒带/南寒带）：极圈以内（有极昼极夜）

## 二、地图三要素 ■背

### 1. 比例尺

| 考点 | 内容 |
|------|------|
| **公式** | 比例尺 = 图上距离 ÷ 实地距离 |
| **表示方式** | 数字式（1:100000）、文字式、线段式 |
| **大 vs 小** | 分母越小→比例尺越**大**→内容越详细、范围越小 |
| **缩放** | 放大时比例尺变**大**，显示范围变**小** |

> **比例尺大小判断口诀**："**分母小→比例尺大→内容详细范围小**"

### 2. 方向

| 判定方法 | 说明 |
|---------|------|
| **指向标** | 箭头指向**北** |
| **经纬网** | 经线指南北，纬线指东西 |
| **一般定向** | 无指向标和经纬网时，"**上北下南，左西右东**" |

### 3. 图例和注记

- **图例**：地图上表示地理事物的符号
- **注记**：地图上的文字说明和数字

## 三、等高线地形图 ■背

### 1. 基本概念

- **海拔**：地面某点高出海平面的垂直距离
- **相对高度**：地面某点高出另一点的垂直距离
- **等高线**：将海拔相同的各点连接成的闭合曲线

### 2. 地形部位判读

| 部位 | 等高线特征 | 掌握等级 |
|------|-----------|---------|
| **山峰** | 闭合曲线，数值从中间向四周降低 | ■背 |
| **山脊** | 等高线向低处凸出（"凸低为脊"） | ■背 |
| **山谷** | 等高线向高处凸出（"凸高为谷"） | ■背 |
| **鞍部** | 两个山峰之间的低洼处 | ◆理解 |
| **陡崖** | 多条等高线重叠 | ■背 |

> **等高线口诀**："**凸高为谷，凸低为脊；等高线密坡陡，等高线疏坡缓**"

### 3. 等高线的应用

| 应用场景 | 判读方法 |
|---------|---------|
| **选择登山路线** | 选等高线**稀疏**处（坡度缓，省力安全） |
| **判断河流流向** | 河流在山谷中，从高处流向低处 |
| **计算相对高度** | 两点海拔相减 |

### 4. 分层设色地形图

- 绿色→平原，黄色→高原/山地，蓝色→海洋

# 地图与地球 · 材料题专项

---

## 材料分析题通用答题模板

### 第一步：读图
- 看图名、图例、比例尺、方向标
- 圈关键数据（等高线数值、经纬度）

### 第二步：计算与判读
- 计算相对高度（两点海拔相减）
- 判读地形部位（凸高为谷、凸低为脊）

### 第三步：应用
- 把地图信息与实际问题结合（登山路线、河流流向）

---

## 一、等高线地形图

### 出题角度

**角度1：给出等高线地形图，要求判读地形部位**

关键判读：
- 闭合曲线中间高四周低 → **山峰**
- 等高线向低处凸出 → **山脊**（"凸低为脊"）
- 等高线向高处凸出 → **山谷**（"凸高为谷"），常有河流
- 多条等高线重叠 → **陡崖**

**角度2：计算相对高度或选择登山路线**

- 相对高度 = 高点海拔 − 低点海拔
- 登山选**等高线稀疏**处（坡度缓，省力安全）

**角度3：比例尺相关计算**

- 比例尺 = 图上距离 / 实地距离
- 放大操作时比例尺变**大**，显示范围变**小**、内容更详细

### 答题要点

- 山峰：h最高
- 山脊：凸低为脊，**分水岭**
- 山谷：凸高为谷，**集水线**（有河流发育）
- 陡崖：适合攀岩，不适合修路

---

## 二、经纬网定位

### 出题角度

**角度1：给出经纬网图，要求判断某点的半球位置**

判断步骤：
1. 看纬度：N北半球，S南半球
2. 看经度：20°W→0°→160°E为东半球（"小小为东"）

**角度2：判断方向（经线指南北，纬线指东西）**

---

## 考前速记

> **凸低为脊凸高谷，等高线密坡陡疏缓**  
> **小小为东大大西，经南纬北定向准**
