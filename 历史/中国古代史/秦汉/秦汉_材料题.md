# 秦汉时期 · 材料题专项

---

## 一、秦始皇巩固统一的措施

### 出题角度

**角度1：给出秦始皇巩固统一的材料，问采取了哪些措施**

常见材料类型：古文摘录（如"一法度衡石丈尺""书同文""车同轨"）、表格填空

**角度2：问这些措施有什么意义**

常见问法："秦始皇的这些措施对国家发展有什么作用？"

**角度3：对比分封制与郡县制**

常考表格题，要求写出两种制度在"官员产生方式""对中央的影响"等方面的区别

### 答题要点

| 考点 | 必答内容 |
|------|---------|
| **政治** | 确立皇帝制、三公九卿制；推行郡县制 |
| **文化** | 统一文字（小篆为标准字体） |
| **经济** | 统一货币（圆形方孔半两钱）、统一度量衡 |
| **交通** | 车同轨，修筑驰道 |
| **意义** | 巩固了统一，促进了经济文化交流发展 |

## 二、汉武帝大一统

### 出题角度

**角度1：给出"推恩令"的材料，问目的和效果**

常见材料："于是藩国始分，而子弟毕侯矣……"

**角度2：给出董仲舒建议的材料，问"罢黜百家，独尊儒术"的影响**

常见问法："这一建议被采纳后产生了什么影响？"

**角度3：综合考查汉武帝巩固大一统的各方面措施**

常以表格或材料组合题形式出现

### 答题要点

| 方面 | 措施 | 作用 |
|------|------|------|
| **政治** | 推恩令 | 削弱诸侯国势力，加强中央集权 |
| **思想** | 罢黜百家，独尊儒术（董仲舒） | 儒家思想成为正统，影响两千年 |
| **经济** | 铸五铢钱，盐铁专卖 | 加强中央财政收入 |
| **军事** | 卫青霍去病北击匈奴，漠北战役 | 北部边境安定 |
| **外交** | 张骞两次通西域 | 促进中西交流，开辟丝绸之路 |

## 三、丝绸之路

### 出题角度

**角度1：给出丝绸之路路线图，要求填写关键节点**

常考填空：长安→河西走廊→敦煌→葱岭→中亚→西亚→欧洲

**角度2：给出双向交流的物品清单，要求分类**

中国输出：丝绸、茶叶、漆器、冶铁技术
西域输入：葡萄、胡桃、苜蓿、石榴、良马

**角度3：问丝绸之路的历史意义**

### 答题要点

- **开辟者**：张骞通西域奠定了基础
- **路线**：长安出发，经河西走廊到中亚、西亚、欧洲
- **意义**：促进了东西方经济文化交流，是古代东西方往来的大动脉
- **现实联系**："一带一路"的历史渊源
