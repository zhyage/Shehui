# 史前时期 · 材料题专项

---

## 材料分析题通用答题模板

### 第一步：读材料
- 看材料出处（考古报告、遗址图片、化石照片等）
- 圈关键词（遗址名、距今年代、出土文物）

### 第二步：联想教材
- 把材料中的考古发现映射到对应的古人类或文化遗址
- 确定考查的是哪个时期的史前文明

### 第三步：组织答案
- 按"是什么→为什么→怎么样"逻辑回答
- 推断类问题注意"论从史出"（考古证据→合理推断）

## 一、考古发现与历史推断

### 出题角度

**角度1：给出考古发现，要求推断古人类的生活方式**

常见对应关系：

| 考古发现 | 可推断结论 |
|---------|-----------|
| 发现门齿化石和粗糙石器 | 该地有过古人类活动，使用打制石器 |
| 发现灰烬层、烧骨、烧石 | 已经使用火（天然火） |
| 发现骨针、装饰品 | 掌握缝纫技术，有审美意识 |
| 发现稻谷遗存、骨耜 | 原始农业出现，种植水稻 |

**角度2：判断史料类型**

常见问法："《史记》中关于炎黄二帝的记载属于第几手史料？" → **第二手史料**（因为是后人撰写）

### 答题要点

- **第一手史料**：化石、遗址、文物、原始档案
- **第二手史料**：史书、回忆录、后人的研究
- 考古发现是第一手史料，最可靠

## 二、河姆渡 vs 半坡对比

### 出题角度

**角度1：给出房屋建筑图片或描述，判断属于河姆渡还是半坡**

**角度2：表格对比题，填写南北方农耕生活的差异**

### 答题要点

| 对比项 | 河姆渡人 | 半坡居民 |
|--------|---------|---------|
| 流域 | 长江流域 | 黄河流域 |
| 房屋 | 干栏式建筑（防潮） | 半地穴式房屋（保暖） |
| 农作物 | 水稻 | 粟（小米） |
| 工具 | 骨耜 | 耒耜、彩陶 |
