## 一、古代亚非文明

### 1. 古埃及 ◆理解

| 项目 | 内容 |
|------|------|
| 发源地 | 尼罗河流域 |
| 文明成就 | 金字塔（法老陵墓）、象形文字、太阳历 |
| 统一 | 约前3100年，美尼斯统一埃及 |

### 2. 古印度 ◆理解

- 发源地：印度河流域
- **种姓制度**：婆罗门（祭祀）→刹帝利（军事贵族）→吠舍（平民）→首陀罗（奴隶）→贱民 ■背
- **佛教**：前6世纪，乔达摩·悉达多（释迦牟尼）创立 ■背

### 3. 古希腊罗马 ■背

| 文明 | 成就 | 掌握等级 |
|------|------|---------|
| **古希腊** | 雅典民主政治（伯里克利时期达到高峰）；《荷马史诗》；奥林匹克运动会 | ■背 |
| **古罗马** | 《十二铜表法》（罗马第一部成文法）；罗马帝国（屋大维建立） | ■背 |

## 二、资本主义的兴起

### 1. 文艺复兴 ■背

- **时间**：14—16世纪
- **核心思想**：**人文主义**（以人为中心）
- **代表人物**：
  - 但丁《神曲》（文艺复兴的先驱）
  - 达·芬奇《蒙娜丽莎》《最后的晚餐》
  - 莎士比亚《哈姆雷特》
- **意义**：为欧洲资本主义社会的产生奠定了思想文化基础

### 2. 新航路开辟 ■背

| 航海家 | 时间 | 成果 |
|--------|------|------|
| **哥伦布** | 1492年 | 发现美洲新大陆 |
| **达·伽马** | 1497—1498年 | 到达印度 |
| **麦哲伦** | 1519—1522年 | 首次环球航行（证明地球是圆的） |

- **意义**：世界开始连为一个整体；欧洲**大西洋沿岸**工商业繁荣；**地中海沿岸**商贸地位衰落；早期的殖民掠夺开始

### 3. 早期殖民掠夺 ◆理解

- 葡萄牙、西班牙最早走上殖民扩张道路
- **三角贸易**：欧洲→非洲（贩卖黑奴）→美洲→欧洲 ■背

### 4. 美洲作物传播（哥伦布大交换）◆理解

新航路开辟后，美洲作物传入中国，丰富了中国的农作物结构：

| 传入中国的美洲作物 | 传入时间 | 影响 |
|------------------|---------|------|
| **玉米、马铃薯、甘薯** | 明朝中后期 | 高产作物，促进人口增长 |
| **花生、向日葵、烟草** | 明朝中后期 | 丰富经济作物种类 |
| **辣椒** | 明朝 | 彻底改变了中国饮食文化 |

> **美洲作物口诀**："**玉米马铃薯甘薯，高产养活了更多人；辣椒花生向日葵，明朝传入中国来**"

## 三、资产阶级革命

### 1. 英国资产阶级革命 ■背

| 项目 | 内容 |
|------|------|
| **时间** | 1640—1688年 |
| **重要文件** | **《权利法案》**（1689年）→限制王权 |
| **结果** | 确立**君主立宪制**（议会高于王权） |

> **英国革命口诀**："**权利法案限王权，君主立宪英国先**"

### 2. 美国独立战争 ■背

| 项目 | 内容 |
|------|------|
| **时间** | 1775—1783年 |
| **重要文件** | **《独立宣言》**（1776年7月4日）→宣告美国独立 |
| **1787年美国宪法** | 确立**三权分立**（立法、行政、司法相互制衡），总统制、联邦制 | ◆理解 |
| **领导人** | **华盛顿**（美国国父） |
| **影响** | 实现了国家独立，确立了民主共和制 |

### 3. 法国大革命 ■背

| 项目 | 内容 |
|------|------|
| **时间** | 1789—1794年 |
| **开始标志** | 1789年7月14日，攻占巴士底狱 |
| **重要文件** | **《人权宣言》**→自由、平等、民主 |
| **1791年法国宪法** | 规定有产者才有选举权，与《人权宣言》的理想存在差距 | ◆理解 |
| **领导人** | **拿破仑**（颁布《拿破仑法典》，巩固革命成果） |
| **评价** | 积极：沉重打击欧洲封建势力；消极：对被占领地区人民进行掠夺与压迫 | ■背 |

> **革命对比口诀**：
> "**英国革命限王权，美国独立反殖民，法国革命反封建**"

## 四、工业革命

### 1. 第一次工业革命（18世纪60年代—19世纪中期）■背

| 项目 | 内容 |
|------|------|
| **首先发生** | **英国** |
| **标志** | **蒸汽机**的广泛使用（瓦特改进） |
| **主要成就** | 珍妮机（哈格里夫斯）、蒸汽机车（史蒂芬森） |
| **影响** | 大机器生产取代手工劳动，人类进入"**蒸汽时代**" |

### 2. 第二次工业革命（19世纪中后期—20世纪初）◆理解

| 项目 | 内容 |
|------|------|
| **标志** | **电**的广泛使用（人类进入"**电气时代**"） |
| **重要发明** | 电灯（爱迪生）、内燃机、汽车（福特）、飞机（莱特兄弟）、电话（贝尔） |
| **垄断组织** | 资本主义进入垄断阶段（帝国主义阶段） |

### 3. 马克思主义与国际共产主义运动 ■背

| 事件 | 时间 | 内容 |
|------|------|------|
| **《共产党宣言》发表** | 1848年 | 马克思、恩格斯为共产主义者同盟起草，**马克思主义诞生**的标志 |
| **第一国际成立** | 1864年 | 国际工人联合组织（马克思领导） |
| **巴黎公社** | 1871年 | 无产阶级建立政权的第一次伟大尝试 |
| **《国际歌》** | — | 鲍狄埃作词，狄盖特谱曲，反映巴黎公社精神 |

> **共产主义运动口诀**："**1848宣言诞，1864第一国际，1871巴黎公社起**"

### 4. 启蒙运动 ◆理解

- **中心**：法国（18世纪）
- **核心思想**：**理性主义**（用理性判断一切）
- **代表人物**：
  - **伏尔泰**：反对封建专制，主张自由平等
  - **孟德斯鸠**：**三权分立**（立法、行政、司法）
  - **卢梭**：人民主权说
- **影响**：为**美国独立战争**和**法国大革命**提供了思想基础，也影响了**拉丁美洲独立运动**

### 5. 俄国农奴制改革与日本明治维新

**俄国农奴制改革**（1861年）◆理解
- **沙皇**：亚历山大二世
- **内容**：废除农奴制，农民获得人身自由
- **影响**：使俄国走上了**资本主义发展道路**

**日本明治维新**（1868年）■背
- **背景**：美国舰队入侵（黑船来航），幕府统治危机
- **内容**：全面学习西方（"脱亚入欧"），废藩置县、发展工业、文明开化
- **影响**：使日本走上**资本主义道路**，成为亚洲强国

### 6. 罗斯福新政 ◆理解

- **时间**：1933年（美国经济大危机后）
- **核心**：**国家干预经济**（政府大规模干预经济生活）
- **措施**：
  - **以工代赈**（兴办公共工程，提供就业）
  - 整顿银行金融体系
  - 调整农业和工业（《全国工业复兴法》）
- **影响**：使美国渡过经济危机，但**没有解决社会根本矛盾**
- **实质**：资本主义制度的**自我调节和完善**

## 五、两次世界大战

### 1. 第一次世界大战（1914—1918年）■背

| 项目 | 内容 |
|------|------|
| **导火线** | 萨拉热窝事件（奥匈帝国皇储斐迪南被刺杀） |
| **两大军事集团** | **三国同盟**（德奥意） vs **三国协约**（英法俄） |
| **重要战役** | **凡尔登战役**（"绞肉机"） |
| **结果** | 同盟国战败，战后形成**凡尔赛-华盛顿体系** |

### 2. 第二次世界大战（1939—1945年）■背

| 项目 | 内容 |
|------|------|
| **全面爆发** | 1939年德国闪击波兰 |
| **德国入侵苏联** | 1941年6月（巴巴罗萨计划） |
| **太平洋战争** | 1941年12月日本偷袭珍珠港 |
| **转折点** | 斯大林格勒战役（二战转折点）；中途岛海战（太平洋战场转折） |
| **诺曼底登陆** | 1944年，开辟欧洲第二战场 |
| **雅尔塔会议** | 美英苏（罗斯福、丘吉尔、斯大林）决定战后世界格局 |
| **反法西斯联盟** | 1942年《联合国家宣言》发表 |

**二战胜利**：1945年5月德国投降；1945年8月日本投降（美国在日本广岛长崎投原子弹，苏联对日宣战）

> **二战口诀**："**1939二战起，1941苏德和太平洋，斯大林格勒转折点，1945终获胜**"

## 六、冷战与当代世界

### 1. 冷战（1947—1991年）◆理解

| 事件 | 内容 |
|------|------|
| **杜鲁门主义**（1947年） | **冷战开始的标志** |
| **马歇尔计划** | 美国援助西欧 |
| **北约 vs 华约** | 两大军事集团对峙 |
| **德国分裂** | 柏林墙（1961年） |
| **苏联解体**（1991年） | 冷战结束，两极格局终结 |

### 2. 多极化趋势 ◆理解

- 冷战结束后，世界格局向**多极化**方向发展
- **一超多强**：美国（唯一超级大国）+ 欧盟、日本、中国、俄罗斯
- **经济全球化**：联合国（UN）、世界贸易组织（WTO）、欧盟（EU）

# 世界史 · 材料题专项

> 本文件梳理该专题中考材料分析题的出题角度和答题要点。

---


## 材料分析题通用答题模板

### 第一步：读材料
- 看材料出处（谁写的、什么书）
- 圈关键词（人名、制度名、主张等）

### 第二步：联想教材
- 把材料中的关键词映射到教材知识点
- 确定考查的是哪个时期、哪个知识点

### 第三步：组织答案
- 按"是什么→为什么→怎么样"的逻辑组织
- 如果是评价类问题，注意 **一分为二**（积极+局限）
- 如果是启示类问题，从 **历史联系现实** 作答

## 一、文艺复兴

### 出题角度

**角度1：给出文艺作品的描述或作品内容，问体现了什么思想**

常见材料：但丁《神曲》批判教会、达·芬奇《蒙娜丽莎》展现人性美、莎士比亚戏剧歌颂人性

考点核心：体现**人文主义**思想（以人为中心，反对神权）

**角度2：问文艺复兴的意义**

### 答题要点

- **核心思想**：人文主义（以人为中心，肯定人的价值和尊严）
- **代表人物**：但丁（先驱，《神曲》）、达·芬奇（《蒙娜丽莎》《最后的晚餐》）、莎士比亚（《哈姆雷特》）
- **意义**：为欧洲资本主义社会的产生奠定了思想文化基础

## 二、英法美资产阶级革命

### 出题角度

**角度1：给出法律文件条文，判断属于哪个国家的革命**

关键区分：
- "凡未经议会同意，以国王权威停止法律……" → **英国《权利法案》**（限制王权）
- "人人生而平等，造物者赋予他们若干不可剥夺的权利……" → **美国《独立宣言》**
- "在权利方面，人们生来是而且始终是自由平等的……" → **法国《人权宣言》**

**角度2：美国1787年宪法与法国1791年宪法**

常见出题方式：
- 给出1787年宪法的内容（三权分立、联邦制），问体现了什么原则
- 给出1791年宪法"有产者才有选举权"，问与《人权宣言》的理想有什么差距
- 对比两部宪法的进步性和局限性

| 宪法 | 内容 | 进步性 | 局限性 |
|------|------|--------|--------|
| **美国1787年宪法** | 三权分立、总统制、联邦制 | 确立民主共和政体 | 最初未废除奴隶制，印第安人不算人口 |
| **法国1791年宪法** | 规定有产者才有选举权 | 确立君主立宪制 | 财产限制违背"人人平等"理想 |

**角度3：考查三个文件的共同点和不同点**

**角度4：对比三国革命的意义**

### 答题要点

| 革命 | 文件 | 结果 | 意义 |
|------|------|------|------|
| **英国** | 《权利法案》（1689年） | 君主立宪制 | 议会高于王权 |
| **美国** | 《独立宣言》（1776年） | 国家独立、共和制 | 实现了民族独立 |
| **法国** | 《人权宣言》（1789年） | 民主共和 | 摧毁封建制度，影响深远 |

**共同点**：都反对专制统治，都确立了资产阶级的统治地位

## 三、第一次工业革命

### 出题角度

**角度1：给出工业革命成就的时间轴或图片，问对应发明**

**角度2：问工业革命为什么首先发生在英国**

**角度3：问工业革命的影响**

### 答题要点

- **首先发生**：英国
- **标志**：蒸汽机的广泛使用（瓦特改进）
- **主要发明**：珍妮机（纺纱）、蒸汽机车（史蒂芬森）
- **影响**：
  - 大机器生产取代手工劳动
  - 人类进入"蒸汽时代"
  - 形成了资产阶级和无产阶级两大阶级

## 四、第二次世界大战

### 出题角度

**角度1：给出二战大事年表，要求排序和对应事件**

**角度2：给出雅尔塔会议材料，问会议内容和影响**

**角度3：问二战胜利的原因和启示**

### 答题要点

| 事件 | 时间 | 内容 |
|------|------|------|
| 全面爆发 | 1939年9月 | 德国闪击波兰 |
| 苏德战场 | 1941年6月 | 德国入侵苏联（巴巴罗萨计划） |
| 太平洋战争 | 1941年12月 | 日本偷袭珍珠港 |

## 七、罗斯福新政

### 出题角度

- 给出1929-1933年经济大危机的数据，问罗斯福新政的措施
- 问"国家干预经济"与自由放任的区别

### 答题要点

- **核心**：国家干预经济（政府大规模干预经济生活）
- **措施**：以工代赈（兴办公共工程）、整顿银行、调整工农业
- **影响**：使美国渡过危机，但没有解决社会根本矛盾
- **实质**：资本主义制度的自我调节和完善
