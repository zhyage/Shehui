# 中华文明的五大特性

> 中考综合题常考点（拱墅区一模30题）

| 特性 | 含义 | 史实例证 |
|------|------|---------|
| **连续性** | 唯一自古延续至今、未曾中断的文明 | 汉字演变（甲骨文→小篆→隶书→楷书） |
| **创新性** | 在继承创新中不断发展 | 都江堰、四大发明、科举制 |
| **统一性** | "大一统"理念贯穿历代政治格局与思想文化 | 秦统一→汉武帝大一统→行省制度 |
| **包容性** | 开放包容、海纳百川，在交流互鉴中焕发新生 | 丝绸之路、佛教传入、孝文帝改革 |
| **和平性** | 和平融入中华民族血脉与基因 | 郑和下西洋（和平外交）、万隆会议 |

> **五大特性口诀**："**一连创，二统包，五和平**"
