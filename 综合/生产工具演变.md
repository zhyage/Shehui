# 中国古代生产工具演变

> 跨朝代专题，多份考卷反复出现

| 时期 | 工具 | 类型 | 说明 |
|------|------|------|------|
| 远古（河姆渡） | **骨耜** | 农耕工具 | 用动物骨骼制成，翻土播种 |
| 春秋战国 | **铁制农具** | 农耕工具 | 铁器出现，大大提高了生产力 |
| 汉代 | **耧车** | 播种工具 | 畜力播种机，提高了播种效率 |
| 曹魏 | **翻车** | 灌溉工具 | 马钧改进，提水灌溉 |
| 唐朝 | **筒车** / **曲辕犁** | 灌溉/耕作 | 筒车靠水力自动提水；曲辕犁轻便灵活 |
| 宋朝 | **秧马** | 拔秧工具 | 拔秧时乘坐，减轻劳动强度 |

> **演变规律**：从石制→**铁制**、从人力→**畜力/水力**、效率不断提高

> **演变口诀**："**骨耜铁农具耧车，翻车筒车曲辕犁，秧马最后来帮忙，生产效率步步高**"
