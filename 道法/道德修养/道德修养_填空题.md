# 道德修养 · 填空题

1. "行己有耻"要求我们知\_\_\_\_\_，懂荣辱，\_\_\_\_\_\_\_\_。

2. "止于至善"要求养成\_\_\_\_\_\_\_\_\_\_的习惯。

3. 社会规则的作用是\_\_\_\_\_\_\_\_\_\_秩序内容和\_\_\_\_\_\_\_\_\_\_秩序实现。

4. 集体利益与个人利益在本质上\_\_\_\_\_\_\_\_，发生冲突时应以\_\_\_\_\_\_\_\_\_\_为重。

5. **中国精神**：民族精神以\_\_\_\_\_\_\_\_\_\_为核心，时代精神以\_\_\_\_\_\_\_\_\_\_为核心。

6. 当代中国爱国主义的本质是坚持\_\_\_\_\_\_、\_\_\_\_\_\_和\_\_\_\_\_\_高度统一。

**参考答案：**
1. 廉耻，有所不为
2. 自我省察
3. 明确，保障
4. 一致，集体利益
5. 爱国主义，改革创新
6. 爱国，爱党，爱社会主义
