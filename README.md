## 关于 PlantUML 图形

所有 PlantUML 图形源码以 ` ```plantuml` 代码块的形式 **直接嵌入在 markdown 文档中**，与文档内容放在一起。

渲染方式：

- **VS Code**：安装 PlantUML 扩展，在 markdown 中直接预览
- **命令行**：用以下命令从 markdown 中提取并渲染
  ```bash
  java -jar plantuml-1.2026.3.jar 历史/中国古代史/先秦/夏商周.md -tpng
  ```
  PlantUML 会自动识别文档中的 ` ```plantuml ` 代码块并生成对应图片。

备用 `.puml` 源文件也在 [综合/](综合/) 目录下。
